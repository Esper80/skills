# PR 생성 성공 후 처리

이 문서는 이 대화의 작업으로 새 PR 생성이 성공한 직후에만 읽고 적용합니다. PR 준비·상태 조회·기존 PR 리뷰·갱신 단계에서는 미리 읽지 않습니다. 스킬 전체나 CI가 끝날 때까지 미루지 않습니다.

## PR 생성 후 스레드명

- 모든 프로젝트에서 이 대화의 작업으로 PR 생성이 성공하면 실제 생성 결과의 PR 번호와 현재 대화 제목을 확인하고, `mcp__codex_app__set_thread_title`로 스레드명을 `#PR번호 기존 스레드명` 형태로 즉시 변경합니다(예: `#11 로그인 오류 수정`). 이 이름 변경은 사용자가 상시 승인했으므로 별도 확인을 묻지 않습니다.
- 한 대화에서 여러 PR을 생성하면 가장 최근 생성한 PR 번호를 사용합니다. 제목 맨 앞에 기존 `#숫자 ` 접두어가 있으면 새 번호로 교체하고 나머지 제목은 보존하며, 번호를 중복으로 붙이지 않습니다. 참고·리뷰·갱신만 한 기존 PR이나 다른 대화에서 만든 PR은 대상이 아니며, 생성 실패 시 제목을 바꾸지 않습니다.
- 이름 변경 후 저장된 제목을 확인합니다. 도구가 없거나 변경에 실패하면 PR 생성 성공과 이름 변경 미완료를 구분해 알립니다. 이 규칙은 PR 게시 자체의 승인을 대신하지 않습니다.
