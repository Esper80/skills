# QA 완료 보고

변경·합격 기준, 실행한 검사와 실제 결과, 발견한 결함·남은 위험, 미실행 항목과 제한, QA 결론을 변경 범위에 맞게 보고합니다. 검증 대상 코드·환경을 식별할 수 있는 정보를 남기고 관찰과 추론을 구분합니다.

독립 검증이 요구됐다면 producer와 독립성의 실제 수준을 밝힙니다. 구현·QA·게시·배포 상태를 구분하며 QA PASS를 전체 작업 완료로 확대하지 않습니다.

Board나 정형 기록이 요청됐으면 실제 생성·읽기 검증 결과와 제한을 보고합니다. 요청되지 않은 Board 상태·17개 항목·업데이트 확인을 일반 답변에 추가하지 않습니다.

기계 검증이나 엄격 QA 계약의 보고는 [엄격 완료 보고](strict-completion-report.md)를 사용합니다. 유지보수 업데이트 확인은 사용자가 요청했거나 해당 운영 정책이 요구할 때만 실행합니다.
